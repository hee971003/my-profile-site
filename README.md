# 김희현 프로필 웹사이트

Java / Spring Boot 기반 백엔드 개발자 김희현의 개인 프로필 사이트입니다. HTML, CSS, JavaScript로 만들었고 스타일링에는 Tailwind CSS CDN을 사용합니다. 빌드 과정이 없어서 파일을 브라우저로 열면 바로 볼 수 있습니다.

- **배포 주소**: https://hee971003.github.io/my-profile-site/
- **저장소**: https://github.com/hee971003/my-profile-site

## 프로젝트 구조

```
my-profile-site/
├── index.html          # 전체 페이지 (Tailwind CDN, 섹션 마크업, 메타 태그)
├── css/
│   └── style.css       # 히어로 배경, 카드, 내비게이션, 타임라인 등 보조 스타일
├── js/
│   └── main.js         # 모바일 메뉴, 스크롤 등장 효과, 타이핑 효과, 숫자 카운트업, 연락처 복사
└── images/
    ├── profile.png     # 히어로 영역 프로필 사진 (원형, 360×468 원본)
    └── og-thumb.png    # 링크 공유 시 보이는 썸네일 (1200×630)
```

## 실행 방법

별도 설치가 필요 없습니다. `index.html`을 브라우저로 열면 됩니다.
Tailwind CSS와 Google Fonts(Noto Sans KR)를 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 주요 기능 (main.js)

- **모바일 메뉴**: 768px 미만에서 햄버거 버튼으로 열고 닫으며, 메뉴 항목을 누르면 자동으로 닫힙니다.
- **스크롤 효과**: 20px 이상 스크롤하면 상단 바가 흰색 블러 배경으로 바뀝니다.
- **등장 애니메이션**: `data-reveal` 속성이 붙은 요소가 화면에 들어오면 나타납니다.
- **타이핑 효과**: 히어로의 역할 문구를 한 글자씩 입력했다 지우며 순환합니다.
- **숫자 카운트업**: `data-count` 속성이 붙은 숫자가 화면에 보이면 0부터 올라갑니다.
- **연락처 복사**: 전화번호와 이메일을 누르면 클립보드에 복사되고 토스트 메시지가 뜹니다.
- **접근성**: `prefers-reduced-motion` 설정이 켜져 있으면 애니메이션을 끕니다.

## 공유 미리보기 (SNS, 메신저)

`index.html`의 `<head>`에 Open Graph 메타 태그가 있습니다.

- `og:title`, `og:description`, `og:url`: 공유 시 제목, 설명, 주소
- `og:image`: `https://hee971003.github.io/my-profile-site/images/og-thumb.png` (일러스트 썸네일)

`og:image`는 전체 주소가 필요해서 주소가 바뀌면 같이 수정해야 합니다. 카카오톡 등은 이전 미리보기를 캐시하므로 바뀐 썸네일이 바로 안 보일 수 있습니다. 이때는 주소 뒤에 `?v=1` 같은 값을 붙여 확인해 보세요.

## 배포

GitHub Pages로 배포합니다. 저장소 `Settings → Pages`에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 설정했습니다. `main`에 푸시하면 1~2분 뒤 반영됩니다.

## 커스터마이징 가이드

- **사진 교체**: `images/profile.png`를 같은 이름으로 덮어씁니다. 원형으로 잘려서 표시됩니다.
- **공유 썸네일 교체**: `images/og-thumb.png`를 1200×630 크기로 덮어씁니다.
- **역할 문구**: `js/main.js`의 `phrases` 배열을 수정합니다.
- **경력 추가·수정**: `index.html`의 `#career` 섹션에서 `timeline-item` 블록을 복사해 수정합니다.
- **색상**: Tailwind 설정(`index.html` 상단)의 `brand` 색과 `css/style.css`의 `:root` 변수를 수정합니다.
